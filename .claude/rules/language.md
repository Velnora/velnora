# Language Rules

These apply to every session and every department role.

- Everything Velnora publishes is in English: code and its comments, commit messages, branch names, issues, pull request titles, descriptions and review comments, changesets, rules, agent files, and everything under `docs/`, job notes and handoffs included.
- Chat with the user follows the user's language. When repository content draws on a chat in another language, write it in English in your own words.
- Velnora is public. Repository content never names a private project, a person other than the maintainer, or anything learned from outside this repository that its owner hasn't published.
