# Contract request

What an Ecosystem role returns when its work needs a capability the engine doesn't offer. The coordinator hands it to the core engineer as the brief for a contract plan.

```md
🤖 Ecosystem <role>: contract request for <issue URL or "chat request">

**Needed for:** <the integration, adapter or tool, and what it must do for its users>

**Missing today:** <what the engine's exports don't offer, with the file you checked>

**Use case:** <the smallest real example that needs it>

**Proposed shape:** <the export, unit capability or lifecycle hook you would want, as a sketch>

**Why not without it:** <what working around it would need, such as an engine internal>
```
