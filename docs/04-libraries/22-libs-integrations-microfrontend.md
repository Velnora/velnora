# @velnora/mf

`@velnora/mf`, at `libs/integrations/microfrontend/`, is a placeholder for a micro-frontend integration: letting one app load another's components at runtime. Its only file is `src/integration/utils/debug.ts`, a `debug` logger named `velnora:mf`. It has no `src/main.ts`, so its build has nothing to build, and its `exports` name files that don't exist. It depends on `debug`.

The two remaining packages are placeholders too, starting with [`@velnora/rpc`](23-libs-rpc.md).
