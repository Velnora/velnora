# Project foundation

This job establishes the foundation for Velnora's organization before creating departments and role implementations. The user requested a deep, actively facilitated discussion and confirmed a hobby origin, a long-term product and company ambition, the user's CEO role, and comprehensive day-to-day project stewardship by the assistant.

## How it works

The [foundation draft](../../../01-products/01-velnora/01-project-foundation.md) separates confirmed context from a proposed collaboration model and unresolved authority. The assistant leads the discussion, offers concrete positions, and advances independent work while preserving the user's decisions and privacy. Department responsibilities will be derived from the agreed foundation rather than adopted automatically from a reference roster.

## How it got here

The user supplied reference material illustrating department contracts, assignments, handoffs, gates, and coordination. They then clarified that Velnora has a different purpose and ownership arrangement and may need substantially different departments and roles. When asked about the first audience, the user described the project as their hobby. The [opening handoff](2026-10-31-session-foundation-discussion.md) records that shift in framing.
